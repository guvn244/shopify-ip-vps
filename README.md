## 先说清楚：Shopify 需要的是“独立 IP”，不是“更快网速”

很多人把 VPS 理解成“提速工具”，但店铺运营场景里它的核心价值是环境隔离。MKCloud 官方文档里有一条非常明确的边界说明：独享 IP 表示当前分配的使用方式，但**不保证地址的历史信誉，也不能保证平台不识别账户关系**。第三方评测也确认过类似结论——Shopify 对卖家用什么 IP 没有硬性规定，问题出在多店铺混用 IP 之后触发的关联判定。

所以合理的预期是：独立 IP VPS 解决的是“多家店不要在同一个网络环境里互相污染”的问题。至于能不能防封，取决于账号资质、运营行为和 IP 的历史记录，这些不是任何一家 VPS 商家能承诺的。

MKCloud 每台 VPS 分配 1 个独立入口 IP 和 1 个独立出口 IP：你从入口 IP 登录服务器，在 VPS 里打开店铺后台，业务流量从出口 IP 访问 Shopify。对多店铺团队来说，这意味着每台机器是一个独立完整的网络环境，不会出现两台机器共用一个出口地址的情况。

## 按 Shopify 运营场景选套餐

不同规模的店铺运营，对应的方案差别很大。下面按三种典型情况拆开说。

### 单人或小团队：一台广港 IEPL 1TB 起步

一个运营管理一两家店，日常就是后台操作、改商品、传素材、看数据，流量压力不大。广港 IEPL 1TB 档（1核/2GB/20GB SSD）月付 ¥358，对这类工作负载是够用的。

这台机器跑的是浏览器环境和运营工具，不是流量大户。1TB 双向流量意味着一个月大概有 500GB 的上行额度，除非天天上传大体积视频素材，否则不太会碰到上限。

建议先用月付试一两个月，记录实际的流量消耗和登录习惯，再决定要不要升档或者加机器。年付虽然便宜，但在没摸清用量之前先锁长期合约，不太划算。

### 多店铺隔离：按“1 店 1 机”计算预算

三家店就要准备三台 VPS，各自有独立的入口和出口 IP，互不混用。按广港 IEPL 1TB 档算，三台机器月付合计 ¥1074，年付合计 ¥12888。

这笔钱买的是：每台机器一个固定的香港 BGP 出口 IP、一个独立的系统环境、互不干扰的登录记录。前提依然是账号本身有多店经营的合规资质——环境隔离只是技术手段，不能替代平台规则。

浏览器指纹要跟 IP 一起隔离，不要在 A 店的 VPS 里打开 B 店的后台，哪怕只是一次。指纹浏览器或独立系统账户都行，关键是登录记录不要交叉。

### 美区店铺或需要持续上传：沪美独享或广港独享带宽

## 购买前必须知道的几条限制

MKCloud 官网在购买流程和知识库里写了几条硬性规则，下单前应该逐条确认：

1. **需要国内实名**。所有产品都要中国身份信息实名认证，具体是手机号+身份证号+姓名的一致性验证。
2. **省级白名单**。为防止机场、回国等违规用途，所有直连专线产品只允许一个省份的 IP 连入。下单时选好省份，开通后只有该省的 IP 能登录，后续可以改。
3. **仅支持支付宝**。官网明确目前只支持支付宝付款，更多支付方式在筹备中。
4. **退款政策严格**。只有质量问题才支持退款，而且需要你在工单里提交具体数据（延迟、测速截图）来证明。服务开通后不支持更换地域，这条下单前想清楚。
5. **出口 IP 不接收 inbound**。出口端不能从外部直接连入，意味着你没法用这台 VPS 直接做网站托管或接支付回调。它的定位就是后台操作环境，不是服务器托管。
6. **升降级走工单**。升级补差价，降级到更低价套餐时差价不退，是否迁移以工单处理结果为准。
7. **没有 SLA**。标准产品不带服务等级协议，对可用性有硬性要求的企业需求，需要提前单独询价。

还有一条容易忽略的：IXP 系列只允许云厂 BGP 网络连入，如果你的办公网络不在支持列表里，这台机器买回来也连不上。IXP 的低价格是以“你已经有云前置”为前提的。

## 常见问题

**Shopify 运营一定要用 VPS 吗？**

不是硬性要求。一家店、一个人、在家里正常运营，用本地网络就行。VPS 的价值在多店铺隔离、团队协作、固定登录环境这几个场景里才体现出来。如果你的店没有被关联判定困扰过，先不买也没问题。

**独享 IP 就能防封吗？**

不能画等号。MKCloud 官方文档的原话是：独享 IP 不证明此前无人使用，也不保证不受网段级策略影响；跳数少不会提高账号权重。防关联的本质是账号资质合规加运营行为干净，独立 IP 只是让多店铺环境不互相污染的基础设施。

**IP 检测分数低就安全了吗？**

不确定。第三方工具的欺诈评分只能做参考，MKCloud 的知识库专门提醒过：工具分数不是平台许可，单次登录结果也不能证明长期可用。店铺的判断标准跟这些工具不完全一样。

**月付和年付怎么选？**

确认过用量和质量之后再考虑长期合约。沪港入门档目前的长期价是季付 ¥864（等于月均 ¥288）、年付 ¥3456（等于月均 ¥288），长期付款确实便宜，但前提是你已经用月付验证过这条线路符合业务需要。

**超流量了怎么办？**

流量计费套餐按上行+下行双向统计，达到额度自动停机。可以在后台自助购买流量重置，或者提交工单补差价升级到更大档位。

**入口 IP 和出口 IP 为什么要分开？**

入口用来登录服务器，出口用来访问 Shopify。分开的好处是你可以限制只有特定省份的 IP 能登录入口，而出口 IP 保持固定不变——对平台来说，这家店的登录环境就是长期稳定的单一地址。
